# PLAN-Z — Event Management and Ticketing

Collaborative MERN university project with attendee, organizer, and administrator roles; JWT authentication; event browsing and approval; booking and ticket generation; merchandise and complaint workflows. Payments are mocked, not production payments.

**Source and contributor credit:** [Original team repository](https://github.com/tashriquetanvir-commits/Git-project). This is a portfolio copy, not a claim of sole authorship.

## Local setup
Install dependencies in `client/` and `server/` with `npm install`. Configure MongoDB and `JWT_SECRET` in `server/.env` (never commit secrets). Start each project with `npm run dev`. See project source for required settings.

## Project status
Course project, not independently verified for production deployment.
